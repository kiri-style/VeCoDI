# split_inference/late

## Purpose
Late-layer artifacts for split inference. Weights are stored encrypted in flash and decrypted into NS RAM at runtime.

## Contents
- `L_nn_wt_encrypted.h`: sizes, offsets, IV, externs
- `L_nn_wt_encrypted_data.c`: encrypted weights array in flash
- `L_nn_biases.h`: bias arrays
- `L_nn_params.h`: CMSIS-NN params/dims for late layers

## Notes
The encrypted weights are generated by tools in [tools/](../../tools/) and consumed by the secure partition for AES-CTR decryption.
